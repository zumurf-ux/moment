# Moment / 잠시

짧고 신뢰할 수 있는 일상 브리핑 서비스의 Firebase 운영 콘솔입니다.

- 정적 HTML 운영 페이지
- Firebase Authentication 및 Cloud Firestore 연동
- Android 사용자 앱은 로컬 D 드라이브 작업본에서 관리
- 관리자 계정은 공개 저장소에 포함하지 않음

## 배포 주소

- 운영 페이지: https://zumurf-ux.github.io/moment/
- 사용자 웹 미리보기: https://zumurf-ux.github.io/moment/user.html

운영 페이지는 GitHub Pages에 배포되며, Firebase Authentication으로 로그인한 관리자만 운영 데이터에 접근할 수 있습니다.
